# KRX 금시장 일별매매정보

금 현물 일별 통계는 한국거래소 OPEN API를 직접 사용한다. 실시간 네이버·KIS
시세와 구분하며 기존 프리미엄 계산의 가격을 일별 종가로 바꾸지 않는다.

- 승인 상품: 금시장 일별매매정보
- HTTPS GET: `https://data-dbg.krx.co.kr/svc/apis/gen/gold_bydd_trd`
- 인증: 서버 전용 `KRX_API_KEY`를 `AUTH_KEY` 헤더로 전송
- 조회: `basDd=YYYYMMDD`, 응답 `OutBlock_1`
- 상품: `04020000` 금 99.99_1kg, `04020100` 미니금 99.99_100g
- `TDD_CLSPRC`/시가/고가/저가 단위 원/g, `ACC_TRDVOL` 단위 g,
  `ACC_TRDVAL` 단위 원. 거래량은 금괴 개수가 아니다.

Render 기존 백엔드의 Environment에 키를 등록하고 해당 API 이용 승인을 받아야
한다. 키는 Vercel이나 `NEXT_PUBLIC_` 변수, Git, 로그에 넣지 않는다.
새 키는 서비스 재배포 후 수집기에 적용된다. 인증 헤더가 다른 호스트로
전달되지 않도록 HTTP 리다이렉트를 따르지 않는다.

리스 소유 수집기만 1시간 간격으로 확인한다. 한국시간 오늘부터 최근 14일을
역순 조회하며 주말을 건너뛴다. 빈 거래일만 과거로 이동하고 인증·전송·응답
오류는 즉시 중단한다. 실패 시 최소 5분 뒤 재시도한다. 수집 과정에서 매 요청
전 리스를 갱신한다. 브라우저 요청과 새로 고침은 공급자 API를 직접 호출하지 않는다.

기존 Supabase 비공개 JSON 스냅샷의 `krx_daily` 절에 보관하므로 새 테이블이나
RLS 변경이 없다. 조회 API는 `GET /api/krx-gold-daily`이다. `trade_date`는 KRX
`BAS_DD`, `fetched_at`은 마지막 성공 조회 시각이며 서로 대체하지 않는다.
당일 자료가 없으면 최근 제공 거래일을 명시한다. 최신 확인 실패 후 기존 자료가
있으면 `refresh_state=delayed`로 표시하고 없으면 503을 반환한다. 2시간 넘게
조회 시각이 갱신되지 않은 경우도 화면에서 확인 지연으로 표시한다.

일별 통계 특성상 휴일에 기준 거래일이 오래됐다는 이유만으로 실시간 시세의
90초 만료 기준을 적용하지 않는다. 다만 API가 읽는 전체 스냅샷과 절의 수집기
상태는 기존 90초 만료 기준을 유지한다.
